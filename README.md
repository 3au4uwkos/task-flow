# Обзор проекта

Это полнофункциональное веб-приложение для управления задачами. Оно представляет собой доску в стиле Kanban, позволяющую пользователям организовывать задачи по колонкам. Пользователи могут создавать, обновлять и удалять задачи, а также перемещать их между колонками. Приложение также включает аутентификацию пользователей и управление рабочими пространствами.

## Технологии

*   **Бэкенд:** Laravel (PHP)
*   **Фронтенд:** Next.js (React/TypeScript)
*   **База данных:** MySQL
*   **Кэширование:** Redis
*   **Контейнеризация:** Docker

## Архитектура

Приложение разделено на две основные части:

*   **`backend`:** Приложение на Laravel, которое предоставляет RESTful API для управления задачами, пользователями и рабочими пространствами.
*   **`frontend`:** Приложение на Next.js, которое предоставляет пользовательский интерфейс для доски управления задачами.

Оба приложения спроектированы для совместной работы, при этом фронтенд делает вызовы API к бэкенду для получения и обработки данных. Вся среда контейнеризована с использованием Docker, что упрощает настройку и запуск приложения в согласованной и воспроизводимой манере.

# Сборка и запуск

## Docker

Рекомендуемый способ запуска приложения — использование Docker. Файл `docker-compose.yml` в корне проекта определяет необходимые сервисы:

*   `mysql`: Сервер базы данных MySQL.
*   `redis`: Сервер Redis для кэширования.
*   `phpmyadmin`: Веб-инструмент для администрирования MySQL.
*   `redis-commander`: Веб-инструмент для администрирования Redis.

Для запуска приложения выполните следующую команду из корня проекта:

```bash
docker-compose up -d
```

## Бэкенд (Laravel)

Для запуска сервера разработки бэкенда перейдите в каталог `backend` и выполните:

```bash
php artisan serve
```

## Фронтенд (Next.js)

Для запуска сервера разработки фронтенда перейдите в каталог `frontend` и выполните:

```bash
npm run dev
```

## Тестирование

### Бэкенд

Для запуска тестов бэкенда перейдите в каталог `backend` и выполните:

```bash
php artisan test
```

### Фронтенд

Для запуска тестов фронтенда перейдите в каталог `frontend` и выполните:

## Структура Приложения

### Бэкенд (Laravel)

Бэкенд построен на фреймворке Laravel и следует стандартной структуре каталогов с некоторыми дополнениями для реализации сервис-репозиторий паттерна.

-   `app/Http/Controllers`: Контроллеры, отвечающие за обработку HTTP-запросов. Основные контроллеры: `AuthController`, `WorkSpaceController`, `ColumnController`, `TaskController`.
-   `app/Services`: Сервисный слой, инкапсулирующий основную бизнес-логику. Для каждой основной сущности (`WorkSpace`, `Column`, `Task`) создан свой сервис.
-   `app/Repositories`: Слой репозиториев, который абстрагирует логику доступа к данным. Это позволяет легко заменять источник данных.
-   `app/Models`: Модели Eloquent, представляющие таблицы базы данных (`User`, `WorkSpace`, `Column`, `Task`).
-   `app/Extra`: Содержит абстрактные классы `AbstractRepository` и `AbstractService` для переиспользования общей логики репозиториев и сервисов.
-   `routes/api.php`: Определяет все маршруты API, защищенные с помощью Laravel Sanctum.
-   `database/migrations`: Миграции для создания схемы базы данных.

### Фронтенд (Next.js)

Фронтенд использует Next.js с App Router, TypeScript и Tailwind CSS для стилизации.

-   `app/`: Основной каталог приложения.
    -   `app/(pages)`: Каждая папка представляет собой маршрут (`/home`, `/kanban`, `/login` и т.д.).
    -   `layout.tsx`: Корневой макет приложения.
    -   `page.tsx`: Главная страница приложения.
-   `components/`: Содержит переиспользуемые React-компоненты.
    -   `ui/`: Компоненты из библиотеки `shadcn/ui`.
    -   Остальные компоненты (`kanban-column.tsx`, `task-card.tsx` и др.) являются специфичными для приложения.
-   `lib/`: Содержит основную логику фронтенда.
    -   `api.ts`: Функции для взаимодействия с API бэкенда.
    -   `auth.tsx`: Логика аутентификации и контекст пользователя.
    -   `workspace.ts`, `kanban.ts`: Определения типов и вспомогательные функции для управления рабочими пространствами и задачами.
-   `hooks/`: Пользовательские хуки, например, `useAuth` для доступа к контексту аутентификации.
